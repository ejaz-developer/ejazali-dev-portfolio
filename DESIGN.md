# Design Direction

## World

The portfolio is an editorial observation sheet for shipped software: a warm chalk ground, dark ink typography, precise rules, and one iridescent signal band. It should feel like a working studio index, not a corporate agency site or a stack of floating cards.

## Color

- Chalk: `#f5f5ef`, the default page ground.
- Ink: `#202420`, used for primary text and high-contrast closing sections.
- Field: `#ffffff`, used sparingly for image and content surfaces.
- Rule: `#d4d8cc`, thin separators and structure.
- Signal orange: `#ef6c4d`, the only saturated interaction color.
- Signal band: mint, rose, violet, and blue in a narrow horizontal spectrum.

## Typography

- Instrument Serif carries the thesis, section titles, project names, and large emotional statements.
- Inter is the readable body face.
- Montserrat is reserved for compact labels, navigation, metadata, and calls to action.
- Display type is oversized and tight, with generous space above headings and restrained copy widths.

## Composition

- The first viewport is a two-column statement: the work thesis on the left, Ejaz's portrait on the right, and a signal band anchoring the transition into selected work.
- Projects are a ruled editorial index. Each row gives the project name and purpose equal weight with its real preview image.
- About and contact use ink fields to create two deliberate pauses in the mostly chalk composition.
- Services are an open list rather than repeated icon cards.
- Mobile collapses every composition to one readable column while preserving the same reading order and full-size proof imagery.

## Motion and interaction

- Entrances are restrained opacity/position reveals for content already present in the DOM.
- Project imagery gains color and a slight scale on hover; links use an underline that draws from the reading edge.
- Reduced-motion users receive the same content without animation.
- Buttons, links, and section anchors retain visible keyboard focus states.
