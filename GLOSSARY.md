# Portfolio

The content domain of Ejaz Ali's personal brand website: the audiences it serves, the assets it publishes, and the language used to describe them.

## Language

**Client**:
A founder or business that pays Ejaz to build or improve a web product. The site's primary audience.
_Avoid_: customer, buyer

**Recruiter**:
A hiring-side reader evaluating Ejaz for employment. The site's secondary audience.
_Avoid_: hiring manager (unless specifically that role)

**Founder MVP**:
A first shippable version of a product, built for a founder to validate a business idea with real users.
_Avoid_: prototype, PoC, alpha

**Business Web App**:
A custom web application that runs a business process, typically replacing spreadsheets or other manual workflows.
_Avoid_: dashboard, platform, portal

**Project**:
A piece of software Ejaz built. The raw material from which Case Studies are written.
_Avoid_: build, gig, job (for self-built work)

**Case Study**:
A narrative document about one Project covering why it was built, the challenges faced, the decisions made, and the effect achieved.
_Avoid_: showcase, portfolio piece, success story

**Post**:
A published article on the blog. Written to answer a real search query a Client would type, structured to be quotable by AI answer engines (answer-first opening, FAQ section, internal links). Distinct from a Case Study, which documents one specific Project.
_Avoid_: article, blog piece, entry

**Effect**:
What a Project achieved, as claimed in its Case Study. Technical outcomes (users, performance, problems eliminated) and business outcomes (revenue, hours saved) count; effort alone does not.
_Avoid_: impact level, effort story

**In Progress**:
A Project state meaning built but not yet publicly deployed; presented with a label and screenshots instead of a live link. An In-Progress Project never has a Case Study page — it graduates to one when it ships.
_Avoid_: WIP, coming soon, beta (unless it truly is one)

**Agentic Engineering**:
Building software systems that orchestrate autonomous AI agents to perform multi-step work. One of Ejaz's claimed skill areas.
_Avoid_: AI development, LLM apps
