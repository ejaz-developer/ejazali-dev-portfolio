## The Problem

Small businesses frequently track stock in spreadsheets updated by several people: versions fork, formulas break, and nobody trusts the numbers by the end of the month.

## The Build

A MERN-stack internal tool with role-based editing, audit history of every stock change, and a dashboard that answers "what needs reordering today" in one screen. Key decisions, and why:

- **Audit log from day one** — the spreadsheet failed because history was untraceable; the replacement had to make every change attributable.
- **No framework magic on the server** — a plain Express API kept the tool easy for any future developer to pick up.

## Challenges

Getting the data model to match how the team actually counts stock (per location, with unrecorded shrinkage) rather than how the spreadsheet pretended it worked.
